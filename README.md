# gaugechord

Gauge validation gates for chord inputs before they hit prod.

**Site:** https://theworker02.github.io/gaugechord/

## Install / run

```bash
git clone https://github.com/theworker02/gaugechord.git
cd gaugechord
node src/cli.js
node --test
```
